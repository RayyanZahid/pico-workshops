# PICO Workshops

Claude for Spatial Computing, Homebrew Club SF, 2026-09-24. Everything for the PICO sessions in one
folder, with one hub page and one server.

```
node serve.mjs          # http://localhost:5180/  (hub, both workshops, PICO's deck)
```

| Folder | What it is |
|---|---|
| `index.html` | The hub: links every deck, guide, lab and setup file |
| `llms.txt` | The same map for agents |
| `vibe-xr/` | Workshop 1, Vibe XR with PICO CLI: WebXR starter, examples, headset scripts, guide |
| `webspatial-academy/` | Workshop 2, PICO WebSpatial Academy: deck, curriculum, labs L1 to L5, setup, emulator evidence |
| `webspatial-academy/partner/pico-cli-quickstart-david-oh/` | PICO's own deck, unmodified |

Each workshop folder is self-contained and has its own `CLAUDE.md`; open Claude Code inside the one
you are working in.
