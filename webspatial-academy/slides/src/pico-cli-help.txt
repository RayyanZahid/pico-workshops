## pico-cli setup --help
Description:
Set up PICO integration for the requested Agent Host

Usage:
  $ pico-cli setup

Options:
  --agent-tool <tools...>  Complete Agent Host set to configure; recorded Hosts omitted from the
                           list are removed (all | claude-code | codex | cursor | copilot | traecli)
  --platform <platform>    Target development platform (spatial | unity)
  --scope <scope>          Plugin resource scope (global | local; defaults to global in
                           non-interactive setup) (global | local)
  --project <path>         Project directory where plugin context should be linked from selected
                           agent context files
  -y, --yes                Accept the generated setup plan without prompting
  -h, --help               Display this message

Examples:
  $ pico-cli setup
  $ pico-cli setup --agent-tool claude-code
  $ pico-cli setup --agent-tool codex traecli --platform spatial
  $ pico-cli setup --agent-tool claude-code --platform spatial
  $ pico-cli setup --agent-tool claude-code --platform spatial --scope global --yes
  $ pico-cli setup --agent-tool claude-code --platform spatial --scope local --project
    /absolute/path/to/project --yes
  $ pico-cli setup --agent-tool claude-code --platform unity

## pico-cli project create --help
Description:
Create a new PICO project

Usage:
  $ pico-cli project create --name <text> --package <text> --template <text> [options]

Options:
  --dir <path>       Output directory (default: current directory)
  --name <text>      [required] Project name
  --package <text>   [required] Package name, e.g. com.example.app
  --sdk-type <text>  Override the SDK type; defaults to the platform recorded in .pico-env.json
                     (spatial | unity)
  --template <text>  [required] Template mode (spatial: planar/volumetric/stage; unity:
                     PICOSpatial/OpenXR/PICOXR)
  --sdk <text>       SDK version override
  --force            Allow overwriting an existing Gradle project in the output directory
  -h, --help         Display this message

Examples:
  # Panel-first app with mostly 2D UI
  $ pico-cli project create --template planar --name demo --package com.example.demo
  # 3D model viewer or product showcase
  $ pico-cli project create --template volumetric --dir apps/demo --name demo --package
    com.example.demo
  # Immersive or room-scale spatial experience
  $ pico-cli project create --template stage --name demo --package com.example.demo --force
  # PICO Spatial Unity app
  $ pico-cli project create --sdk-type unity --template PICOSpatial --name demo --package
    com.example.demo
  # OpenXR runtime app
  $ pico-cli project create --sdk-type unity --template OpenXR --name demo --package
    com.example.demo
  # PICO XR runtime app
  $ pico-cli project create --sdk-type unity --template PICOXR --dir apps/demo --name demo --package
    com.example.demo

## pico-cli editor pack --help
Description:

  $ pico-cli editor pack

Options:
  --workspace-root <path>     Workspace root used to resolve the editor project
  --project <path>            Existing Spatial Editor project (.spatialproject or project directory)
  --scene-files <items>       Comma-separated scene files to package. If omitted, editor defaults
                              are used.
  --target-app-root <path>    Spatial app root. Spatial app projects must write to
                              app/src/main/assets/<bundle-name>.bundle.
  --output-path <path>        Bundle output file path or output directory
  --bundle-name <name>        Bundle base name used for .bundle and .scenes.json (default:
                              editor-asset)
  --sidecar-dir <path>        Directory for .scenes.json. Defaults to the bundle directory.
  --editor-version <version>  Preferred editor version to download
  --wait-timeout <seconds>    Wait for editor ready timeout seconds (default: 120)
  --pack-timeout <seconds>    Max seconds to wait for the pack task to finish before giving up
                              (default: 300)
  --format <format>           Output format (plain | json) (default: json)

  --artifact-checksum <sha256>  Optional SHA-256 checksum for --artifact-url

  --log-file <path>             Write editor and MCP Server logs to this file
  -y, --yes                     Assume yes for prompts
  --headless                    Start the editor in headless mode by default without loading the
                                main window. Use --no-headless to disable it and show the GUI at
                                startup. (default: true)

                           must be used alone (all | claude-code | codex | cursor | copilot |
                           traecli)
  --scope <scope>          [required] Plugin resource scope (global | local)
  --platform <platform>    [required] Desired platform for every selected Host; same-platform
                           records are repaired and different-platform records are blocked (spatial
                           | unity)
  --project <path>         Target application project root for AGENTS context; also contains local
                           resources/state in local scope and defaults to the exact current
                           directory
  --format <format>        Output format (plain | json) (default: plain)
  -y, --yes                Skip confirmation before installing or repairing plugin resources
  -h, --help               Display this message

Examples:
  $ pico-cli plugin install --scope global --agent-tool codex --platform spatial
  $ pico-cli plugin install --scope global --agent-tool codex traecli --platform spatial
  $ pico-cli plugin install --scope global --project /absolute/path/to/project --agent-tool codex
    --platform spatial
  $ pico-cli plugin install --scope global --agent-tool all --platform spatial --yes
  $ pico-cli plugin install --scope local --agent-tool traecli --platform spatial --yes
  $ pico-cli plugin install --scope local --project /absolute/path/to/project --agent-tool all
    --platform unity --yes

                           Host from its recorded platform (spatial | unity)

                           resources/state in local scope and defaults to the exact current
                           directory
  --format <format>        Output format (plain | json) (default: plain)
  -y, --yes                Skip confirmation before uninstalling recorded resources
  -h, --help               Display this message

  $ pico-cli plugin uninstall --scope global --agent-tool codex traecli --yes
  $ pico-cli plugin uninstall --scope global --agent-tool all --platform spatial --yes
  $ pico-cli plugin uninstall --scope global --project /absolute/path/to/project --agent-tool codex
    --yes
  $ pico-cli plugin uninstall --scope global --agent-tool all --yes
  $ pico-cli plugin uninstall --scope local --agent-tool codex --yes
  $ pico-cli plugin uninstall --scope local --project /absolute/path/to/project --agent-tool traecli
    --yes
