=== L5-s1 concept
# Agentic expert: Claude Code runs the loop
img: ../assets/emulator/27-lab5-web-app-night-market.png | The capstone, Night Market, installed as a Web App in the emulator: glass window, and the vendor cards float out over the window's bottom edge; the result the agent loop should produce and prove
lead: Every step you did by hand is a command, so an agent can run them. Your job is to hold it to evidence.

- **The loop:** edit, serve, `pico-cli web launch`, capture, `pico-cli log -l W`, judge against SPEC.md, repeat.
- **Evidence per claim:** a screenshot path, a log line or a DevTools read. "The code looks right" isn't evidence.
- **Bound it:** an iteration cap and a stopping condition.
- **Ground it:** PICO questions go through the `pico-dev-knowledge` MCP, with a cited source.

::: notes
25 minutes: 15 of demo on one attendee's site, 10 of capstone kickoff, then the capstone goes home. Emulator screenshots are sometimes partly black while the app renders fine: that's why the loop needs a cap, or the agent "fixes" an artefact for an hour.
:::

=== L5-s6 step
# Profile it
action: Find the process, then record and analyze a trace.

Confirm which package your page runs in first. On the emulator the PICO Browser is `com.picoxr.browser`.

```cmd
pico-cli app list
```

```prompt
Record a 10 second perf trace while the volume scene is open, run the built-in analysis, and tell me the top three costs and one change for each. Say which of them are the browser's cost and which are mine.
```

```expect
Three costs, each with one change, split into the browser's and yours. Usual suspects: too many enable-xr elements, a heavy GLB, a style loop that runs every frame.
```

::: notes
Run `pico-cli perf doctor` once to install the profiler deps. The trace command under the hood is `pico-cli perf trace record -t 10 --package <pkg> -o trace.perfetto-trace`. Unverified: whether a standalone Web App runs under the browser's package or its own.
:::

=== L5-s7 step
# Ship it
img: ../assets/media/p5-solution-night-market.png | The capstone solution in desktop Chrome: the same URL is a normal website for everyone without a headset
action: Deploy over HTTPS and launch it as a Web App from its manifest.

On PICO OS 6 the HTTPS URL is the distribution. No packaging.

```cmd
pico-cli web launch --manifest-url https://your.site/app.webmanifest
```

```expect
Your site opens as a Web App. The manifest needs name or short_name, start_url and icons.
```

::: notes
Emulator, or a device you own: web launch installs a browser APK first. visionOS is the only target that needs packaging (@webspatial/builder on a Mac). PICO store listing for Web Apps goes through business partnerships.
:::
