Paste this into Claude Code

Open a terminal, run claude, and paste one prompt. Claude sets up the kit, checks your machine, and walks you through the first lab.

Clone https://github.com/RayyanZahid/pico-workshops into this folder. In pico-workshops/webspatial-academy run `npm run labs:install` and then `npm run doctor`, and tell me my track (emulator or web-only). Then read webspatial-academy/CLAUDE.md and walk me through lab 1 step by step, telling me what to look at after each step.

For the Vibe XR workshop instead: clone the same repo, cd pico-workshops/vibe-xr, and follow the guide.

Why nothing pops out

A browser tab is never spatial. Install the page as a web app (monitor icon → Install app), then wait up to 60 s (close and reopen once if the panels are still missing).
